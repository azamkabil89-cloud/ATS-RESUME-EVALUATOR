# ATS Resume Scanner & Scoring App

An AI-powered application that evaluates resumes against Applicant Tracking System (ATS) standards using Streamlit and Gemini Flash.

## Features
- **PDF Text Extraction**: Extracts raw text directly from PDF resumes.
- **ATS Scoring**: Evaluates readability, formatting, and relevance.
- **Tailored Feedback**: Highlights missing keywords, skills, and concrete recommendations.
- **Job Description Matching**: Compares resumes directly against target job listings.
